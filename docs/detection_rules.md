# 부정행위 의심 판정 규칙 (초안)

온라인 시험·면접에서 응시자가 화면이 아닌 곳을 오래 보는 구간을 찾아 기록합니다. 이 프로그램은 컨닝을 확정하지 않습니다. **감독자가 확인할 구간과 그 근거를 보여 주는 도구**입니다.

설정값은 모두 [config/settings.py](../config/settings.py)에 있으며, 팀원 3명의 직접 촬영 데이터로 조정한 뒤 확정합니다.

## 1. 집중 구역 정하기 (5점 보정)

1. 시험 시작 전 화면 중앙과 네 모서리에 점을 하나씩 띄웁니다 (`CALIBRATION_POINTS = 5`).
2. 응시자가 각 점을 2초씩 보는 동안 동공 위치를 모읍니다 (`CALIBRATION_SECONDS_PER_POINT = 2.0`).
3. 모은 동공 위치의 가로·세로 범위에 여유 10%를 더한 것을 **집중 구역**으로 정합니다 (`FOCUS_ZONE_MARGIN = 0.10`).

동공 위치는 눈 영역 안에서의 상대 위치(0~1 비율)입니다. 사람마다 눈 모양과 앉은 자세가 달라서, 고정된 기준 대신 응시자마다 보정합니다.

## 2. 이탈 1회 세기

| 종류 | 조건 | 설정값 |
| --- | --- | --- |
| 시선 이탈 | 동공 위치가 집중 구역을 1초보다 오래 벗어남 | `DEPARTURE_SECONDS = 1.0` |
| 자리 이탈 | 얼굴이 1초보다 오래 검출되지 않음 | `FACE_MISSING_SECONDS = 1.0` |

1초 이하로 잠깐 벗어나는 것(짧은 시선 움직임)은 세지 않습니다. 정확히 1초도 세지 않습니다.

- 이탈 시간은 벗어난 순간부터 돌아온 순간까지 전체를 셉니다 (1초를 뺀 나머지가 아님).
- 얼굴은 보이는데 동공 위치가 없으면(눈 깜빡임 등) 직전 상태를 유지합니다. 깜빡임 때문에 이탈이 생기거나 끊기지 않습니다.
- 시선 이탈 중 얼굴이 사라지면 시선 이탈을 닫고 자리 이탈을 새로 시작합니다.

구현: [src/attention_detection.py](../src/attention_detection.py)

## 3. 부정행위 의심 표시

시선 이탈과 자리 이탈을 **따로** 세며, 어느 한쪽이라도 아래 기준 중 하나에 도달하면 **부정행위 의심**입니다. 화면 2의 게이지는 이 기준을 끝(100%)으로 표시합니다.

| 기준 | 초안 값 |
| --- | --- |
| 이탈 횟수 | 5회 이상 (`SUSPICIOUS_DEPARTURE_COUNT`) |
| 이탈 누적 시간 | 30초 이상 (`SUSPICIOUS_TOTAL_SECONDS`) |

### 결과 화면 목록 (화면 3)

| 색 | 의미 | 순서 |
| --- | --- | --- |
| 빨강 | 1초 넘게 벗어난 이탈 1건 | 오래 벗어난 순서 |
| 노랑 | 누적 기준(횟수·시간)에 처음 도달한 시점 | 빨강 아래, 시각 순서 |

제목 형식: `A학생 | 의심 시간(시험 시작 후 00시00분00초)`. 항목마다 근거 기록의 체인값을 조회할 수 있습니다. 판정은 현재 설정이 아니라 **기록 당시 저장된 기준**으로 합니다.

구현: [src/report.py](../src/report.py)

## 4. 기록과 무결성

기록 폴더: `logs/sessions/<시작시각>_<학생>/`

| 파일 | 내용 |
| --- | --- |
| `session.json` | 학생, 시작 시각, 시험 시간, 판정 기준, 키 생성 정보, 종료 기록 |
| `events.csv` | 이탈 1회당 한 줄: 순번, 종류, 시작·종료(시험 시작 후 ms), 지속 시간, 체인값 |
| `events.csv.sha256` | 종료 시점 `events.csv` 전체의 SHA256 |

**감독관 패스워드와 체인값**

1. 시험 시작 전 감독관이 패스워드(6자 이상)를 정합니다.
2. 패스워드로 키를 만듭니다 (PBKDF2-HMAC-SHA256, 20만 번 반복, 무작위 salt). **패스워드와 키는 저장하지 않습니다.** 결과 조회 때 패스워드가 맞는지 확인할 값만 저장합니다.
3. 첫 체인값은 시험 정보로 만들고, 이후 `체인값 = HMAC-SHA256(키, 이전 체인값 + 이번 기록)`으로 이어 갑니다. 종료 기록까지 체인에 이어 붙입니다.
4. 결과를 조회할 때 패스워드로 키를 다시 만들어 모든 체인값을 다시 계산합니다.

| 위·변조 | 검출 결과 |
| --- | --- |
| 기록 한 줄 수정 | 그 줄의 체인값 불일치 |
| 중간 기록 삭제 | 순번 건너뜀 + 다음 줄 체인값 불일치 |
| 마지막 기록 삭제 | 종료 기록의 체인값·이탈 수 불일치 |
| 시험 정보(기준값 등) 수정 | 첫 체인값 불일치 |
| 기록 수정 후 SHA256 파일도 새로 계산 | SHA256은 통과해도 체인값 불일치 (키가 없으면 다시 만들 수 없음) |
| 프로그램 비정상 종료 | 저장된 이탈 기록은 검증 가능, "종료 기록 없음" 표시 |

명령줄 확인: `python -m src.report logs/sessions/<기록 폴더> --chain`

영상과 얼굴 이미지는 저장하지 않습니다.

## 5. 알려진 한계

- 화면 옆에 붙인 메모처럼 집중 구역 안에 있는 자료는 찾지 못합니다.
- 다른 사람의 도움(음성, 화면 밖 사람)은 탐지 범위가 아닙니다. 현재는 얼굴 1명만 검출합니다.
- 조명·안경·카메라 위치에 따라 동공 검출이 불안정할 수 있어, 촬영 데이터로 검출률을 확인해야 합니다.
- 패스워드가 숫자 6자리면 경우의 수가 100만 개라 기록 파일을 가진 사람이 시간을 들이면 맞힐 수 있습니다. 실제 사용에서는 더 긴 패스워드가 필요합니다.
- 기록 폴더 전체를 지우는 것은 막을 수 없습니다. 최종 체인값을 감독관이 따로 보관하면 바뀐 기록으로 바꿔치기한 것은 확인할 수 있습니다.
